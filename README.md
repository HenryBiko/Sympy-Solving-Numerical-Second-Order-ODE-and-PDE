# Solving Second-Order ODEs and PDEs with SymPy and SciPy

Symbolic and numerical solutions to harmonic oscillator equations, plus frequency analysis of sound waves.

## What's inside

- **Analytical solutions:** general solutions to homogeneous second-order linear ODEs with constant coefficients (e.g. `y'' + ω²y = 0`, where `ω = √(k/m)`) using SymPy
- **Numerical solutions:** solving the same systems with SciPy and comparing against the analytical results
- **Signal analysis:** converting sound into a waveform and finding its dominant frequencies, the basis for targeting frequencies in noise-cancelling earbuds
